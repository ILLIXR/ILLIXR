Sets up the Vulkan environment.

This function initializes the Vulkan instance, selects the physical device, creates the Vulkan device, gets the graphics and present queues_, creates the swapchain, and sets up the VMA allocator.

Exceptions
runtime_errorIf any of the Vulkan setup steps fail.
