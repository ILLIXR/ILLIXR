virtual bool ILLIXR::network::network_backend::is_topic_networked ( std::string  topic_name)
pure virtual

Used to query if a topic is networked.

The backend should coordinate with the other endpoints to determine if a topic is networked. There are two cases where this should return true:

  1. topic_create has been called with the same topic_name
  2. topic_create has not been called with the same topic_name, but the topic is networked by another endpoint The backend implementation should coordinate with the other endpoints to determine if a topic is networked.
    Parameters
    topic_nameThe name of the topic.
