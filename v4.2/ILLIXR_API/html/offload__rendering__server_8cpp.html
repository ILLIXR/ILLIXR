Detailed Description

Offload Rendering Server Implementation.

This file implements the server-side component of ILLIXR's offload rendering system. It captures rendered frames, encodes them using hardware-accelerated encoding, and sends them to a remote client for display.

Two encoding backends are supported:

  • FFmpeg with NVENC (default): Uses FFmpeg's Vulkan-CUDA hwaccel pipeline
  • Direct NVENC (compile with -DNVENC_ENCODER): Uses NVENC directly without FFmpeg
