    Detailed Description

    Extends head_pose_data with linear and angular velocity reported by the OpenXR runtime via XrSpaceVelocity. Each velocity component carries its own validity flag because the runtime may provide one without the other.

    Velocities are expressed in the same reference space as the pose (local space by convention in this plugin) and in SI units: * linear_velocity — metres per second * angular_velocity — radians per second (axis-angle, right-hand rule)
