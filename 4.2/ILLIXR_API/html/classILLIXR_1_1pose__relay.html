◆ pose_map_

std::map<XrTime, pose_map_entry> ILLIXR::pose_relay::pose_map_
mutableprivate

Cache of previously computed extrapolated poses keyed by XrTime, so repeated get_pose() calls for the same time avoid redundant work. Each entry carries the id of the combined_pose it was derived from so offload_rendering_server can correlate frames back to headset poses. Declared mutable so it can be populated from const get_pose().
